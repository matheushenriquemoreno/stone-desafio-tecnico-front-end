## Convenções

Os arquivos seguem o padrão `ADR-NNN-nome-curto.md`. Cada ADR vigente registra status, data, contexto, decisão, consequências e alternativas consideradas.

A documentação mantém apenas decisões vigentes. Quando uma decisão mudar, a ADR substituída e suas referências devem ser removidas, e o índice deve ser atualizado.
